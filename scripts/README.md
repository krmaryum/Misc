# Scripts

This folder contains reusable automation scripts for Linux, DevOps, Docker, Kubernetes, and CI/CD tasks.

## Structure

| Folder | Purpose |
|---|---|
| `linux/` | Linux user and system administration scripts |

## Available Scripts

| Script | Description |
|---|---|
| `linux/create-linux-user.sh` | Cross-platform Linux user creation script |

## Usage

Go to the script folder:

```bash
cd scripts/linux
```
